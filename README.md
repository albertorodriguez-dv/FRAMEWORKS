## Description

This project is a TypeScript starter application built with the [NestJS](https://github.com/nestjs/nest) framework.

## Project setup

```bash
npm install
```

## Compile and run the project

```bash
# development
npm run start

# watch mode
npm run start:dev

# production mode
npm run start:prod
```

## Run tests

```bash
# unit tests
npm run test

# end-to-end tests
npm run test:e2e

# test coverage
npm run test:cov
```
